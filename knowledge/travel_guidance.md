# Travel planning reference

## How to use this reference

This local knowledge base contains stable planning guidance for the demo. It is
not a live booking database and it must not be used as proof of current prices,
availability, opening hours, weather, visa rules, or transport schedules. Live
facts come from the typed tool results and are marked with their provider.

## Tokyo

东京塔（Tokyo Tower） is a named landmark that can be placed in an itinerary when the
traveler explicitly requests it. Anime-focused plans commonly consider
Akihabara and Ikebukuro as themes, but the planner should prefer verified place
candidates returned by the POI tools whenever available.

## Hong Kong

维多利亚港（Victoria Harbour） is an outdoor waterfront preference. On rainy or very hot days
the itinerary should balance it with an indoor museum, market, or other
indoor-capable activity when the tool results provide one. The final plan must
still show the weather returned by the weather tool rather than this reference.

## Planning principles

Group nearby places on the same day when the route tool has coordinates for
them. Keep the user's named preferences visible, and treat unstated budget,
hotel style, meal choice, and exact activity time as optional planning details.
If a public data provider is unavailable, say so instead of replacing its
missing result with a model guess.

## Data boundaries

The local reference supports explanations and planning heuristics only. It does
not authorize bookings, payments, scraping, or claims about live inventory.
Flight and hotel candidates in this project are demo adapter results unless a
future provider adapter explicitly marks them as live.
